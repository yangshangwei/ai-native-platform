## Phase 4: 数据可视化

### 目标
引入图表库，实现数据可视化

### 任务清单

1. **选择图表库**
   - 评估 Chart.js vs ECharts

   - 推荐：Chart.js (更轻量)

2. **实现图表组件**

3. **集成到现有页面**
   - 工作台页面：Token 使用趋势

## Phase 6: 深色模式

### 目标
实现完整的深色模式支持

### 任务清单

1. **深色模式设计 Token**
   - 定义深色配色方案

3. **用户偏好持久化**

4. **深色模式测试**
   - 所有页面深色适配
   - 图表颜色适配
   - 对比度验证

## 实施顺序

### 优先级排序

1. **Phase 3** (高优先级)
   - 直接提升用户体验
   - 统一视觉风格
   - 预计耗时：2-3 小时

2. **Phase 5** (中高优先级)
   - 提升交互流畅度
   - 无需外部依赖
   - 预计耗时：1-2 小时

3. **Phase 4** (中优先级)
   - 增强数据展示
   - 需要引入外部库
   - 预计耗时：2-3 小时

4. **Phase 6** (中低优先级)
   - 可选功能
   - 依赖 Phase 3-5 完成
   - 预计耗时：2-3 小时

### 执行策略

**批量处理**:
- Phase 3：一次性优化所有页面
- Phase 5：一次性添加所有动画
- Phase 4：分批集成图表
- Phase 6：最后实现深色模式

**质量保证**:
- 每个 Phase 完成后运行质量审查
- 浏览器实际验证
- 性能指标检查
