### 2. 关键指标卡片化 ✅

**新增功能**: 在交付报告顶部增加 4 个指标卡片

**卡片内容**:
1. **门禁检查**: `14/14` 
   - 状态颜色：失败(红)、警告(黄)、全部通过(绿)
   - 描述：显示失败/警告数量或"全部通过"

2. **测试结果**: `6/6`
   - 状态颜色：全通过(绿)、有失败(红)、无测试(灰)
   - 描述：自动化测试 / 暂无测试

3. **命令执行**: `2`
   - 状态颜色：有命令(蓝)、无命令(灰)
   - 描述：真实命令执行 / 暂无命令

4. **产物证据**: `7`
   - 状态颜色：有产物(信息蓝)、无产物(灰)
   - 描述：查看全部产物 / 暂无产物

**技术实现**:
- 使用 `metricCardV2` 组件（与工作台风格一致）
- 数据来源：`buildRunProjection(detail)` 投影
- 布局：响应式 4 列网格（移动端自动折叠）

### 3. CSS 样式支持 ✅

**新增文件**: `apps/web/public/components.css` 末尾

**新增样式**:
