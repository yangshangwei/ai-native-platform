# 重构运行配置页面UI - 更简洁易用的设计

## 背景

当前运行配置页面信息密度过高，视觉层次不清晰，用户截图显示：
- 每个配置项占用过多垂直空间
- 多个badge和summary grid造成视觉噪音
- 技术细节默认展开，影响浏览效率
- 编辑区域默认展开，页面显得拥挤

## 目标

1. **降低视觉噪音**：减少默认可见的信息量，聚焦核心配置项
2. **提升扫描效率**：用户能快速找到需要修改的配置
3. **保持功能完整**：所有现有功能（编辑、历史、重置）都保留，只是调整展示方式
4. **参考最佳实践**：借鉴 Stripe/VS Code/GitHub 的设计模式

## 核心改进点

### 1. 视觉状态指示优化
- **当前**：pills显示"未保存/已覆盖/默认值"和"高/中/低风险"
- **改进**：
  - 使用左侧 4px 彩色边框表示状态（未保存=橙色，已覆盖=蓝色，默认=灰色）
  - 风险标识只对"高风险"显示红色badge，中低风险不显示
  - 状态pill简化为一个

### 2. 信息层次重组
- **当前**：每个配置卡片显示4个summary items（当前值、状态、风险、最近变更）
- **改进**：
  - **一级信息**（默认可见）：配置名称、当前值预览、状态badge、操作按钮
  - **二级信息**（hover/focus）：完整描述、"上次修改"tooltip
  - **三级信息**（点击展开）：技术详情、编辑器、历史记录

### 3. 编辑交互简化
- **当前**：`<details open>` 默认展开编辑区域，所有行都显示input/textarea
- **改进**：
  - 默认折叠编辑区域，只显示配置项概览
  - 点击 [编辑] 按钮才展开编辑界面
  - 编辑中的配置项自动展开（dirty state）

### 4. 技术详情默认折叠
- **当前**：技术详情（配置键、类型、来源）可展开，但视觉上与编辑区域平级
- **改进**：
  - 默认折叠，只在需要时展开
  - 使用更轻量的视觉样式（虚线分隔、小字号）

### 5. Toast通知反馈
- **当前**：保存时按钮显示"保存中..."，成功后无明显反馈
- **改进**：
  - 保存成功后显示toast通知："✓ [配置名称] 已保存"
  - 配置行短暂显示绿色checkmark（2秒后消失）
  - 失败时toast显示错误信息

### 6. Danger Zone分组（可选，低优先级）
- 将"高风险"配置单独分组到页面底部
- 默认折叠，标题显示"⚠️ 高风险配置 - 3项"

## 视觉设计

### 配置行布局（默认状态）

```
┌────┬────────────────────────────────────────────────┐
│ ●  │ Max Retries                            [3]     │
│    │ Maximum retry attempts before failing          │
│    │ 已覆盖 · [编辑] [历史]                          │
└────┴────────────────────────────────────────────────┘
```

### 配置行布局（编辑状态）

```
┌────┬────────────────────────────────────────────────┐
│ 🟠 │ Max Retries                            [3]     │
│    │ Maximum retry attempts before failing          │
│    │ 未保存 · [保存] [取消]                          │
│    │ ┌─ 编辑配置 ──────────────┐                   │
│    │ │ [   5    ]  ← number input │                │
│    │ │ [重置为默认值] [历史]       │                │
│    │ └──────────────────────────┘                   │
│    │ ▾ 技术详情（折叠）                             │
└────┴────────────────────────────────────────────────┘
```

### 颜色编码

```css
/* 左侧边框状态指示 */
.config-row { border-left: 4px solid var(--line); }
.config-row.dirty { border-left-color: var(--warn); background: var(--warn-bg); }
.config-row.overridden { border-left-color: var(--info); }
.config-row.recently-saved {
  border-left-color: var(--good);
  /* 2秒后移除此class */
}
```

## 实现范围

### 文件修改
1. `apps/web/src/page-settings.ts` - 核心渲染逻辑
2. `apps/web/index.html` - 少量CSS调整（边框、折叠默认状态）

### 功能保留（不修改）
- 三个overview cards（运行状态、配置变更、常用操作）
- Tab navigation（coordinator/runner/shared/debug）
- 所有编辑功能（save/reset/copy/history）
- 数据加载和API调用逻辑

### 新增功能
- Toast通知组件（保存成功/失败）
- "recently saved"临时状态（2秒后自动清除）

## 验收标准

1. ✅ 配置行默认高度降低至少30%（通过折叠编辑区域和技术详情）
2. ✅ 左侧彩色边框清晰指示配置状态（dirty/overridden/default）
3. ✅ 保存成功后显示toast通知，配置行短暂显示绿色高亮
4. ✅ 技术详情默认折叠，用户明确点击才展开
5. ✅ 高风险配置显示红色badge，中低风险不显示
6. ✅ 编辑区域默认折叠，只有dirty状态或点击[编辑]后才展开
7. ✅ 所有现有功能（编辑/保存/重置/历史）正常工作

## 非目标

- 不改变数据结构或API调用
- 不添加搜索/过滤功能（未来迭代）
- 不重构settings-projection.ts（纯view model，不需要动）
- 不实现Danger Zone分组（可选功能，优先级低）
