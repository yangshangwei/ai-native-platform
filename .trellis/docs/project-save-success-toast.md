# 项目保存成功提示修复

## 问题描述
在项目接入页面点击"保存修改"按钮时，虽然保存成功，但页面会重新加载，用户体验不佳。应该显示一个"保存成功"或"保存失败"的友好提示消息。

## 修复内容

### 1. 状态管理 (`apps/web/src/state.ts`)
- 在 `ui` 对象中添加了 `lastSuccess` 属性用于存储成功消息
- 类似于现有的 `lastError` 属性

### 2. 页面渲染 (`apps/web/src/shell.ts`)
- 更新 `renderPage()` 函数以同时支持成功和错误消息的显示
- 添加 `renderSuccess()` 函数，渲染绿色成功通知框
- 成功消息使用 `.notice.good` CSS 类（样式已存在于 `index.html` 中）

### 3. 项目提交逻辑 (`apps/web/src/page-projects.ts`)
- 修改 `submitProject()` 函数：
  - 成功保存后设置 `ui.lastSuccess` 消息而不是静默重新加载
  - 区分"新接入"和"修改保存"两种场景的成功消息
  - 失败时清除成功消息，确保只显示错误
  - 所有错误场景都清除成功消息

## 用户体验改进
- ✅ 保存成功后显示绿色提示消息："项目'XXX'接入成功" 或 "项目'XXX'修改已保存"
- ✅ 不再重新加载整个页面
- ✅ 数据仍然会更新，但用户不会感觉到页面刷新
- ✅ 保持与现有错误提示的一致性

## 验证
- ✅ TypeScript 类型检查通过
- ✅ 成功消息 CSS 类已存在于样式文件中
- ✅ 代码符合项目现有模式和约定

## 测试建议
1. 新接入一个项目，验证成功提示
2. 编辑现有项目，验证修改成功提示
3. 触发失败场景（如网络错误），验证错误提示正常显示
4. 确认页面不会出现"刷新"效果
